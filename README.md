# HW3P2 solution

Filled-in copy of [`student_handout`](../student_handout). The directory layout matches the handout so tests import `hw3lib` the same way.

Run tests with this directory as the working directory:

```bash
cd hw3p2/solution
python tests/test_norms.py
```

`hw3lib/` here implements the modules that are stubs in the handout. `tests/` matches the handout tests. `config.yaml` and `requirements.txt` are the JAX handout files.

The starter notebook stays in `student_handout/` only. It is student instructions; the answers are these Python files.
